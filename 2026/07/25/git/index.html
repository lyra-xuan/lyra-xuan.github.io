Git是什么

Git 是一个分布式版本控制系统，用于跟踪文件变化并协调多个开发人员之间的工作。

Git 的工作流程

  • 工作区：在本地创建的目录，用于存储项目文件。
  • 暂存区（Staging Area）：用于暂存文件变化的区域。
  • 本地仓库：在本地创建的仓库，用于存储项目的历史记录。
  • 远程仓库：在远程服务器上创建的仓库，用于存储项目的公共版本。
