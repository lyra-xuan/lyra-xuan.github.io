Hexo 常用命令速查

命令 缩写 作用
hexo new "文章标题" hexo n 新建一篇文章，Markdown 文件自动生成至 source/_posts
hexo new page "页面名" - 新建独立页面
hexo clean - 清理 db.json 与 public/ 缓存
hexo generate hexo g 生成静态文件到 public/ 目录
hexo server hexo s 启动本地预览服务器（-p 5000 可指定端口）
hexo deploy hexo d 部署到远程仓库
hexo list post - 查看全部文章列表

常用组合：

  • 本地预览三连：hexo clean && hexo g && hexo s
  • 部署三连：hexo clean && hexo g && hexo d

配置项 说明
menu 顶部导航栏
favicon 网站图标
avatar 侧边栏头像
social 社交图标与链接
highlight_theme 代码块高亮主题
wordcount 字数统计（需安装 hexo-wordcount）
busuanzi 不蒜子访问统计 PV/UV
comments 评论系统，可选 Giscus / Waline
footer.copyright 页脚版权信息
background 全局背景图或渐变
card_css 卡片风格
pagination.prev-next 上下篇导航开关
