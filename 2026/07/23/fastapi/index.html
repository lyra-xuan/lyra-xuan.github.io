前置知识

HTTP 协议

简介

  • HTTP（超文本传输协议，Hypertext Transfer Protocol）是一种用于从网络传输超文本到本地浏览器的传输协议。它定义了客户端与服务器之间请求和响应的格式。HTTP 工作在 TCP/IP 模型之上，通常使用端口 80。
  • HTTPS（超文本传输安全协议，Hypertext Transfer Protocol Secure）是 HTTP 的安全版本，它在 HTTP 下增加了 SSL/TLS 协议，提供了数据加密、完整性校验和身份验证。HTTPS 通常使用端口 443。

HTTP消息结构

  • 请求消息（Request Message）：客户端向服务器发送的请求，包含请求行、请求头和请求体。
  • 响应消息（Response Message）：服务器向客户端发送的响应，包含状态行、响应头和响应体。

请求行

  • 请求行（Request Line）：包含请求方法、请求资源路径和 HTTP版本号。
  • 请求方法（Request Method）：指定客户端对服务器的请求类型，如 GET、POST、PUT、DELETE 等。
  • 请求资源路径（Request Resource Path）：指定客户端请求的资源路径，如 /api/users。
  • HTTP版本号（HTTP Version）：指定客户端和服务器支持的 HTTP 版本，如 HTTP/1.1 或 HTTP/2.0。
  • 请求头（Request Headers）：包含客户端对服务器的请求信息，如 User-Agent、Accept、Content-Type 等。
  • 请求体（Request Body）：包含客户端对服务器的请求数据，如表单数据、JSON 数据等。

响应行

  • 响应行（Response Line）：包含状态码、状态描述和 HTTP版本号。
  • 状态码（Status Code）：表示服务器处理请求的状态，如 200 OK、404 Not Found 等。
  • 状态描述（Status Description）：对状态码的详细描述，如 OK、Not Found 等。
  • 响应头（Response Headers）：包含服务器对客户端的响应信息，如 Content-Type、Content-Length 等。
  • 响应体（Response Body）：包含服务器对客户端的响应数据，如 HTML 页面、JSON 数据等。

状态码

  • 200 OK：请求成功，服务器返回请求的数据。
  • 400 Bad Request：客户端请求有错误，服务器无法理解。
  • 404 Not Found：服务器无法找到请求的资源。
  • 500 Internal Server Error：服务器内部错误，无法完成请求。

HTTP content-type

  • Content-Type：指定请求或响应的媒体类型，如 application/json、text/plain 等。

MIME 类型

  • MIME 类型（MIME Type）：指定文件的媒体类型，如 image/jpeg、application/json 等。
