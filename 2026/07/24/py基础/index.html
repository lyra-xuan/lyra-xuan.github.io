Python 基础语法

Python 标识符

  • Python 中的标识符是区分大小写的。
  • 以单下划线开头的 _foo 代表不能直接访问的类属性，需通过类提供的接口进行访问，不能用 from xxx import * 导入。
  • 以双下划线开头的 __foo 代表类的私有成员。
  • 以双下划线开头和结尾的 __foo__ 代表 Python 里特殊方法专用的标识，如 __init__() 代表类的构造函数。
  • Python 可以同一行显示多条语句，方法是用分号 ; 分开。

行和缩进

  • Python 中的行和缩进是必须的，不能省略。
  • 缩进的空白数量是可变的，但所有代码块语句必须包含相同的缩进空白数量。
  • 可使用反斜杠 \ 来续行代码，但不建议使用，会降低代码可读性。
  • 可使用三引号 ''' 或 """ 来续行代码，但不建议使用，会降低代码可读性。

print 输出

  • print 默认输出是换行的，如果要实现不换行需要在变量末尾加上逗号 ,。

变量

  • Python 中的变量赋值不需要类型声明。
  • 每个变量在内存中创建，都包括变量的标识、名称和数据这些信息。
  • 每个变量在使用前都必须赋值，变量赋值以后该变量才会被创建。
  • Python 所有变量都是「标签（引用绑定）」，不存在 C++ 那种 “变量 = 内存盒子”。
  • Python 允许同时为多个变量赋值：

变量的类型

Python 有五个标准的数据类型：

  • Numbers（数字）
  • String（字符串）
  • List（列表）
  • Tuple（元组）
  • Dictionary（字典）

Numbers（数字）

  • Python 中的数字有整数（int）、浮点数（float）和复数（complex）三种类型。
  • 整数（int）：没有小数部分的整数。
  • 浮点数（float）：有小数部分的数。
  • 复数（complex）：实数和虚数的组合，用 j 表示虚数部分。

内置函数：

  • abs()：返回数字的绝对值
  • int()：将字符串转换为整数
  • float()：将字符串转换为浮点数
  • complex()：将字符串转换为复数

内置方法：

  • int.real()：返回整数的实部
  • int.imag()：返回整数的虚部
  • float.real()：返回浮点数的实部
  • float.imag()：返回浮点数的虚部
  • complex.real()：返回复数的实部
  • complex.imag()：返回复数的虚部

String（字符串）

  • Python 中的字符串是用引号 ' 或双引号 " 包围起来的字符序列。
  • Python 中无 char 类型，所有字符都是字符串。

字符串截取规则：

  • 字符串的索引从 0 开始，所以第一个字符的索引是 0。
  • 字符串的索引可以是正数，也可以是负数。正数即为正数第几个（从 0 开始），负数即倒数第几个（从 -1 开始）：

内置函数：

  • len(str)：返回字符串的长度
  • ord(char)：返回字符的 ASCII 码
  • chr(ascii)：将 ASCII 码转换为字符
  • str(obj)：将对象转换为字符串
  • int(str)：将字符串转换为整数
  • float(str)：将字符串转换为浮点数
  • complex(str)：将字符串转换为复数

内置方法：

  • str.count()：返回字符串中指定子字符串的出现次数
  • str.index()：返回子字符串的第一个索引
  • str.find()：返回子字符串的第一个索引，如果不存在则返回 -1
  • str.replace()：将子字符串替换为新的子字符串
  • str.strip()：删除字符串首尾的空格
  • str.lstrip()：删除字符串左侧的空格
  • str.rstrip()：删除字符串右侧的空格
  • str.title()：将字符串转换为标题格式

List（列表）

  • Python 中的列表是用方括号 [] 包围起来的元素序列。
  • 列表可以包含不同类型的元素，包括数字、字符串、元组、字典等。
  • 列表的元素可以是可变的，也可以是不可变的。
  • 列表的元素可以是其他列表，形成嵌套列表：

Python 列表脚本操作符：

  • 列表对 + 和 * 的操作符与字符串相似。+ 号用于组合列表，* 号用于重复列表。
  • in 操作符：用于检查元素是否在列表中。
  • not in 操作符：用于检查元素是否不在列表中。

内置函数：

  • len()：返回列表的长度
  • max()：返回列表中最大的元素
  • min()：返回列表中最小的元素
  • sum()：返回列表中所有元素的总和
  • sorted()：返回一个排序后的列表，原列表不变

内置方法：

  • list.count()：返回列表中指定元素的出现次数
  • list.index()：返回列表中指定元素的第一个索引
  • list.append()：在列表末尾添加元素
  • list.remove()：删除第一个匹配的元素
  • list.pop()：删除并返回最后一个元素
  • list.insert()：在指定位置插入元素
  • list.sort()：对列表进行排序
  • list.reverse()：反转列表

Tuple（元组）

  • Python 的元组与列表类似，不同之处在于元组的元素不能修改。
  • 元组的元素可以是其他可变类型，如列表、字典等。
  • 元组可以进行拼接和重复操作，但不能删除单个元素值，可以整个删除。
  • 元组使用小括号 ()，列表使用方括号 []。

内置函数：

  • len()：返回元组的长度
  • max()：返回元组中最大的元素
  • min()：返回元组中最小的元素
  • sum()：返回元组中所有元素的总和
  • sorted()：返回一个排序后的元组，原元组不变

内置方法：

  • tuple.count()：返回元组中指定元素的出现次数
  • tuple.index()：返回元组中指定元素的第一个索引

Dictionary（字典）

  • Python 中的字典是用大括号 {} 包围起来的键值对序列。
  • 字典的键必须是不可变的，如数字、字符串、元组等。
  • 字典的值可以是任意类型，包括其他字典、列表、元组等。
  • 字典的键值对之间用逗号 , 分隔：

内置函数：

  • len(dict)：返回字典的键值对数量
  • max(dict)：返回字典中键的最大值
  • min(dict)：返回字典中键的最小值
  • sum(dict)：返回字典中所有值的总和
  • sorted(dict)：返回一个排序后的字典，原字典不变

内置方法：

  • dict.clear()：清空字典所有条目
  • dict.copy()：返回字典的一个浅拷贝
  • dict.get()：返回指定键的值，如果键不存在则返回 None
  • dict.items()：返回字典的所有键值对
  • dict.keys()：返回字典的所有键
  • dict.values()：返回字典的所有值

Set（集合）

  • Python 中的集合是用大括号 {} 模块围起来的无序不重复元素序列。
  • 集合中的元素是不可变的（如数字、字符串、元组），但集合本身是可变的。
  • 集合不支持索引和切片操作。

创建空集合：

内置函数：

  • len(set)：返回集合的元素个数
  • max(set)：返回集合中最大的元素
  • min(set)：返回集合中最小的元素

内置方法：

  • set.add()：向集合中添加元素
  • set.remove()：删除集合中的指定元素，不存在则报错
  • set.discard()：删除集合中的指定元素，不存在不报错
  • set.pop()：随机删除并返回一个元素
  • set.clear()：清空集合
  • set.union()：返回两个集合的并集
  • set.intersection()：返回两个集合的交集
  • set.difference()：返回两个集合的差集

日期和时间的格式化输出参数：

  • %Y：年份，4位数
  • %m：月份，2位数
  • %d：日，2位数
  • %H：小时，24小时制，2位数

  • %W：星期几，0-53，星期日是 0

函数

  • Python 中的函数是用 def 关键字定义的。
  • 函数可以有参数，也可以没有参数。
  • 函数可以有返回值，也可以没有返回值。
  • 函数可以嵌套定义，也可以递归调用。
  • 函数可以作为参数传递给其他函数，也可以作为返回值返回：

参数传递

在 Python 中，类型属于对象，变量是没有类型的。

可更改(mutable)与不可更改(immutable)对象

  • 可更改对象：列表、字典、集合等
  • 不可更改对象：整数、浮点数、字符串、元组等
  • 可更改对象在函数中修改会影响到函数外的变量，而不可更改对象在函数中修改不会影响到函数外的变量：

参数

Python 中的函数参数有四种：

  • 位置参数：按位置传递的参数
  • 默认参数：有默认值的参数
  • 可变参数：可以传递任意数量的参数
  • 关键字参数：按关键字传递的参数
