AI取名全栈项目实战

发表于2026-09-24|更新于2026-09-24|实战项目
|浏览量:

项目简介

AI取名服务是一个前后端分离的全栈应用：用户通过邮箱验证码完成注册登录后，填写姓氏、性别、名字字数、风格偏好等参数，后端调用 DeepSeek 大模型生成包含名字拼音、寓意、评分等结构化信息的取名结果。一套前端代码可同时发布为 H5 网页、Android APK 安装包、微信小程序。

  • 博客地址：Lyra’s Blog
  • 项目地址：lyra-xuan/AI_naming
  • 参考文档：AI取名项目实战

功能概览

  • 前端页面：注册、登录、取名主界面（参数表单 + 结果卡片列表）
  • 后端 API：邮箱验证码发送、用户注册、登录鉴权、刷新 Token、AI 取名
  • 用户体系：JWT 双 Token 鉴权（access + refresh）、邮箱验证码注册、密码哈希存储
  • AI 能力：接入 DeepSeek 大模型，通过 Prompt 工程约束输出结构化 JSON（名字 + 拼音 + 寓意 + 评分）
  • 工程化：环境变量密钥管理、Alembic 数据库迁移、依赖清单、.gitignore 规范

工程化改造与注意事项

密钥管理：从硬编码到环境变量

代码中的敏感信息（数据库密码、SMTP 授权码、JWT 密钥、API Key 等）不得直接写入源代码文件，统一通过环境变量注入。

改造步骤：

  1. 安装 python-dotenv
  2. 新建 .env（存放本地真实配置）与 .env.example（公开占位模板）
  3. 在 .gitignore 中加入 .env，确保不会提交到仓库
  4. settings/__init__.py 中通过 os.getenv("KEY", "fallback") 读取
  5. 业务模块从 settings 统一导入配置，避免多处散落

部署与打包

uni-app 一套代码支持多端发布，以下是三种常用方案：

方案一：H5 网页部署（服务器）

  1. 前端构建：npm run build:h5 → 生成静态文件目录 dist/build/h5/
  2. 后端部署：上传 FastAPIProject_zhiliao/ 到云服务器，使用 Gunicorn + UvicornWorker 启动
  3. Nginx 反向代理配置：
    • yourdomain.com/ → 前端静态资源目录
    • API 路径 → 转发至本机 127.0.0.1:8000
  4. 生产环境调整：http.js 的 BASE_URL 修改为正式域名；CORS allow_origins 收紧为指定域名

方案二：打包为 Android APK

  1. 注册 DCloud 开发者中心，创建应用获取 AppID
  2. 在 manifest.json 中填入 AppID 与应用名称
  3. 将 http.js 中的 BASE_URL 改为服务器公网地址（移动端 127.0.0.1 指向设备本身）
  4. 下载 HBuilderX 并登录相同账号，打开 take_a_name 工程目录
  5. 菜单路径：发行 → 原生App-云打包 → 勾选 Android + 使用公共测试证书
  6. 等待构建完成后下载 .apk 文件，传输至安卓设备安装

暂无服务器时，可使用 cpolar / 花生壳等内网穿透工具将本地 8000 端口暴露至公网进行测试。

方案三：微信小程序

  1. 在 manifest.json 中填入微信小程序 AppID
  2. HBuilderX 菜单：发行 → 小程序-微信
  3. 使用微信开发者工具打开生成目录 dist/dev/mp-weixin/ 进行预览与上传
